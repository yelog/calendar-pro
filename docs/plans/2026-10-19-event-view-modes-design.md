# 日程「单日 / 总览」切换设计

**目标：** 将所选日期的日程与 PR #7 的跨日期列表合并到一个日程区域，避免同时展示相同条目。

**状态：** 已实现，维护者已验收单行标题栏与视图切换，准备随原 PR #7 合入。

## 名称与布局

- 区域统一叫「日程」，标题行右侧放 macOS 原生小号分段控件「单日 / 总览」（英文 Day / Overview），不再独占一行。左侧标题与条目数量按文字基线对齐，数量使用次要颜色和等宽数字。
- 单日的新建按钮紧跟左侧数量，切换控件始终右对齐，避免切换模式后横向跳动。控件按本地化文字的固有宽度布局，保留原生键盘操作和辅助功能标签。
- 标题始终完整显示；空间不足时，单日进度计数改用「3 / 12」的紧凑格式，悬停提示和辅助功能仍提供完整说明。
- 「单日」跟随月历选中的日期，保留时间线、条目计数与新建入口。
- 「总览」以今天为起点按日期分组，保留加载更早和未来分页。名称不限定近期，也不承诺一次加载所有条目。
- 总览移入原日程位置，删除独立的「全部日程」标题、折叠和默认展开控件；提醒事项看板继续位于日程下方。

## 状态和设置

- 新偏好 `eventListMode` 记住上次选择，缺失或未知值默认 `.day`。
- 保留 `showEvents` 和 `showUpcomingSection` 作为两种视图的独立可用性开关；只有一种启用时直接显示它，两种都关闭时隐藏区域。
- 某视图暂时被禁用时回退到另一种可用视图，保留之前的选择，重新启用后可以恢复。
- 设置页分别命名「单日日程」与「日程总览」，清楚说明两个视图共用同一区域且来源可独立配置。
- 旧 `upcomingDefaultExpanded` 字段继续解码和编码以兼容已有配置，当前界面不再使用它。
- 查询和分页只加载当前有效视图；切到总览或重开弹层时重新加载第一页，离开总览时使其旧请求失效。

## 验证

覆盖偏好持久化、旧配置/未知值回退、启停后的有效视图选择；构建并运行相关单元测试。手动检查分段控件、日期切换、总览分页、弹层重开、中文/英文以及看板共存。

本次实现保留 #8 提醒事项看板与两套独立来源设置。既有分页、重复提醒等问题另行处理。
