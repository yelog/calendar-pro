# 统一所选日期摘要设计

**日期：** 2026-10-08
**状态：** 已实施；自动化测试通过，真实菜单栏弹层的视觉验收待完成
**背景：** Issue #5 完整农历展示后的截图反馈
**实施计划：** [2026-10-08-unified-date-summary.md](2026-10-08-unified-date-summary.md)

## 目标

把公历、完整农历、节日和休班状态整合为月历下方的一个日期摘要。默认单行，空间不足时把标签整体移至第二行；完整日期保持可见。

## 当前问题

- `CalendarPopoverView.selectedDayInfoSection` 只有标签非空才出现，普通日缺少公历日期锚点。
- `lunarDateRow` 位于 `infoStripsSection`，公历与农历被分隔线及可选天气卡片隔开。
- 公历使用 10.5 pt，农历使用 12 pt 且额外缩进 14 pt，同类信息的层级与对齐不一致。
- `selectedCalendarDay` 从 `monthDays` 查找选中日期，翻月后选中日期离开网格会丢失标签，农历却继续显示。
- 所有 `.status` 标签采用同一颜色，无法像网格一样区分红色休假和蓝色补班。

## 信息结构

```text
月份标题
月历网格
统一日期摘要
分隔线（存在天气或宜忌时）
天气（可选）
宜忌（可选）
番茄钟、日程及底部操作（沿用现有结构）
```

摘要始终对应 `selectedDate ?? currentDate`；不依赖天气、宜忌、事件、菜单栏农历 token 开关或日期是否在当前网格中。

## 布局状态

### 单行：默认

```text
10月1日 周四  农历 丙午年八月廿一  [国庆节] [休]
```

340 pt 弹层、左右各 16 pt，净宽 308 pt。前期 AppKit 字体估算中，截图样例约需 270 pt；实际结果以 SwiftUI 渲染为准。

### 两行：标签较多或较长

```text
公历日期 星期  农历 完整年月日
[节日] [另一个纪念日] [休]
```

日期与标签是两个布局组。整体不能单行容纳时，标签组整体进入下一行；标签组内部再按完整标签自然换行。

### 极端宽度

若日期组自身超宽，公历和农历改为上下排列。若单个标签宽于整个摘要，则标签内部允许多行，标签容器随内容增高。不能通过缩小字号、横向滚动、截断或移入悬浮提示保留核心信息。

## 视觉规范

| 项目 | 规范 |
| --- | --- |
| 摘要宽度 | 使用父视图净宽，常规 308 pt |
| 左侧对齐 | 与月历和卡片外边缘对齐，无额外 14 pt 缩进 |
| 公历月日 | 12 pt Medium，主要文字色 |
| 星期 | 12 pt Regular，次要文字色 |
| 农历前缀 | 11 pt Regular，次要文字色 |
| 农历年月日 | 12 pt Regular，主要文字色 |
| 日期内部间距 | 公历组与农历组 8 pt；月日与星期 4 pt |
| 日期与标签组 | 8 pt 起，使用紧凑自然宽度布局 |
| 标签 | 节日 10 pt Medium，状态 9.5 pt Medium，最小高度 19/17 pt |
| 标签间距 / 行间距 | 4 pt / 5 pt |
| 月历与摘要 | 8 pt，移除旧摘要的 -3 pt 顶部补偿 |
| 表面 | 无独立背景、无额外卡片或竖线 |
| 状态 | 休为红色，班为蓝色，同时保留文字 |

节日与节气复用原有低对比度标签色。公历、农历尽量基线对齐，标签在单行中垂直居中。不给点击日期和摘要高度变化添加显著弹簧动画。

## 数据与交互规则

1. 普通日期也显示公历摘要；中文功能可用时显示完整农历，英语界面保留公历和适用标签。
2. 翻月不自动更换选中日期；摘要的节日、农历与选中日期同时保持。
3. 当选中日期与当前显示月份不在同一公历年时，公历标题补年份；无障碍文本始终包含完整公历年份。
4. 标签依赖当前地区和节假日配置，保留现有去重及优先级。禁用节假日集合后不从原始农历节日字段重新注入被禁用的标签。
5. 节假日解析失败时保留公历和农历，标签为空，不使整个摘要消失。
6. 日期格式化器显式使用显示日历时区，不能在公历、农历和标签之间混用默认时区。
7. 返回今天、跨日跟随、历史日期锁定沿用现有 ViewModel 行为。
8. 组合朗读顺序：完整公历日期、星期、完整农历、节日、休班状态。“休 / 班”分别朗读“休息日 / 补班日”。标签不提供按钮语义。

## 代码架构

- `Features/Calendar/SelectedDateSummary.swift`：可测试的摘要数据和工厂，按目标日期调用 `CalendarDayFactory.makeDay`、`LunarService.describe`，格式化日期并组装标签。
- `CalendarDayDisplayMetadata.Chip.Style`：把 `.status` 拆为 `.dayOff` 和 `.workday`，不通过本地化文字推断语义。
- `Views/Popover/SelectedDateSummaryView.swift`：三层布局回退、标签外观、无障碍文本，以及只服务于该组件的标签换行布局。
- `RootPopoverView`：由现有状态派生摘要，传递给 `CalendarPopoverView`。
- `CalendarPopoverView`：移除重复摘要/农历块及旧标签辅助方法；信息区只负责天气和宜忌。

`ViewThatFits(in: .horizontal)` 选择首次能容纳的候选；单行候选保留理想宽度，防止被压缩后误判为可容纳。最终候选允许纵向增长。标签换行使用 SwiftUI `Layout`，测量与放置复用同一行规划逻辑，不引入第三方库。

实施时，已存在于当前月历网格内的选中日复用 `monthDays` 的节日解析结果；翻月后选中日离开网格时，摘要工厂单独解析该日期，从而既避免月内的重复查询，又保留跨月日期标签。

## 验收

- 国庆截图样例在 308 pt 净宽内单行；普通日不隐藏公历。
- 长标签按组换行，极长单标签内部换行，无内容省略。
- 翻月离开网格仍保留原日期标签，跨年标题无歧义。
- 四种天气/宜忌组合、语言切换和菜单栏 token 格式均符合规则。
- 深浅色、休班语义、VoiceOver、实际弹层高度验证完成。
- 算法测试、现有回归和构建通过；UI Runner 启动失败必须单独记录，不能视为 UI 验收通过。
